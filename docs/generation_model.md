# 生成模型与一致性设计

本文档说明程序化生态区域生成与演化的计算模型、可复现性边界、跨区块接缝处理、
增量重算与全量重建的等价性证明要点，以及并发、快照、取消的内部约定。

## 1. 坐标与数据模型

* 世界是无限的二维整数格。区块边长 `CHUNK_SIZE = 16`，区块 `(cx, cz)` 拥有
  世界格 `wx ∈ [cx*16, (cx+1)*16)`、`wz` 同理；负坐标用**地板除**映射，
  因此每一格恰好属于一个区块，不存在重复归属或遗漏。
* 区块 `Chunk` 是**不可变值对象**：`coord`、单调递增 `version`、
  `params_digest`（产出它的参数状态摘要）和 256 个 `ChunkCell`
  （`elevation / temperature / moisture / water / biome`）。
* 存储层（`ChunkStore`）从不原地改区块，只在一把锁下整体替换，读者无锁读取，
  任何时刻读到的都是某个完整版本。

## 2. 确定性基线（需求 1）

所有随机性都来自固定位宽整数算术的 SplitMix64（`worldgen/rng.py`），不依赖
`hash()`、字典迭代序、线程调度或系统时间（快照 id 使用时间但**不参与地形**）。

基线段全部是 `(seed, wx, wz)` 的纯函数（`worldgen/terrain.py`）：

* `value_noise2`：在 16 格晶格上取哈希随机值并做 smoothstep 双线性插值，
  世界连续且落在 `[0,1)`；
* `fbm2`：多倍频分形叠加；
* `base_elevation / base_temperature / base_moisture / base_water` 由若干
  fbm（温度叠加纬度带）组合。

因为输入只有世界坐标，A 区块在接缝处对 `(15, z)` 取值与 B 区块对同一世界格
取值调用的是**同一个函数同一个坐标**，天然逐位相同。

参数状态（区域集合 + 种子）有稳定的 SHA-256 摘要：区域按 id 排序、各偏置用
`repr(float)` 序列化。重叠区域以 **id 字典序最大者获胜**，与插入顺序无关，
从而并发/重试得到同一赢家。摘要写入区块，可用来排查"同一格为何不一致"。

## 3. 跨区块接缝连续性（需求 2）

基线本身世界连续。区域偏置若在区域边缘阶跃，松弛后仍会残留断崖，因此
`RegionParams.border_blend_cells`（默认 8 格）定义一条世界连续的渐变带：

```
d     = 到最近区域边缘的格数
k(d)  = smoothstep(clamp(d / width))          # 0..1
bias_effective = bias * k(d)
```

`d` 只依赖世界坐标，接缝两侧区块算出的 `k` 完全相同；偏置在带内平滑过渡到 0。
随后的松弛（下节）再进一步抹平高频，保证接缝处梯度与区块内部步长同量级。
测试 `tests/test_boundary.py` 同时校验"同一世界格两侧逐位相同"和
"跨缝跳变不超过内部步长的数倍 / 远小于原始偏置阶跃"。

## 4. 传播、收敛与终止性（需求 3）

每个可变场（温度、湿度、水）使用**同步 Jacobi** 松弛（`worldgen/propagation.py`），
一轮内所有格只从上一轮的快照读取：

```
x' = (1-α)x + α * avg(四邻)        # 温度 α=0.20，湿度 α=0.20
水再叠加一项有界下坡流动（α=0.15，下坡系数 0.05，并裁剪到 ≥0）
```

性质：

1. **顺序无关**：同步更新 + 固定的行列遍历 + 浮点结合顺序固定，结果不依赖
   区块切分、请求顺序或线程调度。
2. **终止性（无死循环）**：新值是旧值与四邻的凸组合，算子在 sup 范数下是压缩
   映射，邻域差值每轮严格衰减。依赖图成环或存在长链路只影响信息扩散速度，
   不会造成循环不收敛。轮数始终被 `max_propagation_rounds = K` 硬截断。
3. **影响半径**：K 轮后某格只依赖切比雪夫距离 ≤ K 的初始格；对应区块半径
   `ceil(K / CHUNK_SIZE)`（K=4/8/16 时均为 1 个区块）。
4. **收敛判据**：一轮中三个场、全部格的最大绝对变化 `max_delta ≤
   convergence_tolerance` 即提前停止。默认容差 0 → **严格跑满 K 轮**（推荐，
   因为提前停止会让"跑了几轮"依赖具体数据，破坏增量/全量逐位相等）。
   未达容差时由 `non_converged_policy` 决定接受或抛 `NonConvergedError`。

## 5. 增量重算 == 全量重建（需求 3 的核心）

记无限域/全世界上跑满 K 轮的结果为参考解。一次局部 pass：

1. 取写集 W（发生改参的区块 ∪ 其 `ceil(K/16)` 邻域，并与已存在区块求交）；
2. 模拟域取 W 的世界格矩形，再向四周扩 **K 格** halo；
3. halo 内所有格都按 `(seed, 世界坐标, 当前参数)` 即时生成基准初值，
   **不读取**已提交邻块的旧结果；
4. 在该矩形上跑同样 K 轮 Jacobi，域外通过回调始终返回基准值；
5. 只物化 W 中的区块；halo 区块永不返回。

**等价性要点**：K 轮 Jacobi 的依赖半径是 K。W 内任意格距离模拟域外边界至少
K 格，因此它在全部 K 轮中读取到的都是"与全世界同初值"的格，结果与全量重建
逐位相同。halo 越深成本越高，故默认选最小充分深度 K（格）。

**未受影响不被改写**：写集被限制在"改参区块 + 影响半径"且必须已存在；物化后
再与存储中的当前版本逐格比较，**内容相同的区块直接跳过、不产生新版本**。
所以 `recompute()` 在稳态下返回空列表。

**一致性条件**：改动区与世界边缘之间应留有 ≥ K 格的已生成或可即时模拟空间
（测试统一使用比改动区大一圈的世界）。未生成邻块按基准值参与模拟且不落地，
日后真正生成时仍得到同一结果。

## 6. 并发控制（需求 4）

* **读者**：无锁；区块不可变，安装是字典整体替换，读到的非空区块必为完整版本。
* **写事务**：对写集按 `(cx, cz)` 规范序获取区块锁（单一全局序 ⇒ 无
  持有-等待环 ⇒ 无死锁），`lock_timeout_seconds` 仅作死锁兜底。
* **乐观提交（CAS）**：持锁计算后记录写集当前版本，`put_many(chunks, expected)`
  在存储锁下比对；若期间被其他事务抢先提交则整批拒绝。计算是纯函数，
  **重试得到完全相同的区块**，最多重试 `max_commit_retries` 次。
* 参数注册表与脏区集合由一把元数据锁串行化；地形计算本身在区块锁内进行，
  互不相交的请求可完全并行。

## 7. 快照与回退（需求 5）

快照是 append-only 日志（`SnapshotBook`），状态显式三态：

* `IN_PROGRESS`：`begin_snapshot()` 建立，捕获可能尚未完整，**不可回退**；
* `COMMITTED`：`snapshot()`（一步到位）或 `commit_snapshot()` 后成为一致
  恢复点；
* `ABORTED`：放弃的中间态，回退会抛 `SnapshotError`。

提交态快照保存当时全部区块与区域注册表。回退先获取世界中所有区块锁（不会与
在途写入交叉），再整体替换存储与注册表并清空脏区。由于回退恢复了产出结果所需
的**全部输入**（种子在 config 中不变、区域状态一致），从该版本继续生成与
"直接在历史版本上生成"走的是同一条确定性流水线，结果一致（测试
`test_continue_after_rollback_matches_direct`）。

## 8. 取消与超时（需求 6）

`CancelToken` 是线程安全的协作标志，可带 `monotonic` 截止时间。生成在**阶段
边界**检查：每轮传播前、每个区块物化前、提交前。标志置位或超时后抛
`CancellationError / GenerationTimeout`，且由于检查都发生在 `put_many`
之前，**不会安装任何区块**，不留下半更新。重新触发即从最后一次提交态重新走
确定性流程，仍满足可复现与增量/全量一致。

## 9. 模块索引

| 模块 | 职责 |
| --- | --- |
| `coords.py` | 区块/世界坐标、矩形扩张 |
| `rng.py` | SplitMix64 定点 PRNG 与哈希混合 |
| `terrain.py` | 值噪声/fbm/基线场、世界连续偏置解析 |
| `fields.py` | 矩形稠密场 + 域外基准值回调（halo 等价性关键） |
| `propagation.py` | 定序 Jacobi 松弛、有界轮数、收敛判定 |
| `vegetation.py` | 纯确定性群系分类与区块物化 |
| `params.py` | 区域注册表、稳定获胜规则、摘要 |
| `pipeline.py` | 无锁纯计算：halo 模拟 + 只物化写集 |
| `locks.py` / `store.py` | 排序锁表 / 不可变版本化存储与 CAS |
| `snapshot.py` / `world.py` | 快照日志 / 门面：事务、重算、回退、取消 |
